## 3. 角色与维度

### 3.1 角色（默认 user.role，ADMIN 可切换）
| 角色 | 视角 | AI 总结/建议重点 |
|------|------|------------------|
| CSM | 客户视角 | 超时风险、客户优先级、上线情况 |
| PO | 产品视角 | 版本排期、工时饱和度、需求合理性 |
| RD | 研发视角 | 相似需求合并、技术风险、阻塞识别 |
| QA | 测试视角 | 影响范围、回归范围、测试点 |

### 3.2 维度（3 个并列 checkbox，可叠加）
| 维度 | 取值 |
|------|------|
| 时间 | 今日 / 本周 / 本月 / 超期 |
| 紧急性 | P0 / P1 / P2 / P3 |
| 模块 | 按业务模块名 |

未选任何维度时：两列内不分组，平铺。

## 4. 数据流

| API | 用途 |
|-----|------|
| `GET /api/requirements?mine=1&role={role}` | 我的需求 |
| `GET /api/requirements` | 全量（ADMIN 看板） |
| `GET /api/board/ai-summary?role={role}` | 角色视角 AI 总结 |
| `GET /api/board/ai-advice?role={role}` | 角色视角 AI 建议（抽屉） |

## 5. 后端新增

### 5.1 `GET /api/board/ai-summary?role=RD`
- 复用「自读+traecli 纯 LLM」架构
- 输入：当前角色 + mine/all 需求列表（标题/状态/优先级/模块/客户/目标版本/创建时间）
- 输出 Markdown 总结（≤300 字）

### 5.2 `GET /api/board/ai-advice?role=RD`
- 同上但 prompt 强调「可执行建议」
- 输出 Markdown 建议（≤500 字，分点）

### 5.3 4 角色 prompt 模板
- CSM：「你是 CSM。看待板上的需求：哪些客户即将超期？哪些需升级？客户优先级是否合理？」
- PO：「你是产品经理。看排期：本版本容量？工时饱和？哪些需求排不下？」
- RD：「你是研发。看相似需求：哪些可合并？技术风险？阻塞依赖？」
- QA：「你是测试。看影响范围：哪些模块需回归？测试重点？历史 bug 风险？」

## 6. 前端改造

### 6.1 Board.tsx
- 增加 `currentRole` state（默认 user.role）
- 增加维度 state：`dims = { time, urgency, module }: {boolean}`
- 顶部 4 卡片保留
- 角色视角 AI 总结卡片（可折叠）
- 维度切换器（3 checkbox）
- 两列按维度组合分组渲染
- 右上角「AI 建议」按钮 → Drawer

### 6.2 新组件
- `BoardAiSummary.tsx`（角色视角总结卡）
- `BoardAiAdvice.tsx`（抽屉）
- `BoardDimensionSwitch.tsx`（维度 checkbox 组）

### 6.3 角色配置 roleConfig.ts
- 4 角色每角色一份配置：
  - `summaryPrompt`: AI 总结的视角指令
  - `advicePrompt`: AI 建议的视角指令
  - `groupByTime(ctx, mine)`: 时间分组
  - `groupByUrgency(ctx, mine)`: 紧急性分组
  - `groupByModule(ctx, mine)`: 模块分组

## 7. 兼容性

- 保留「待你处理」+「负责中的任务」两列
