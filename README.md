# AI · SOP 需求交付平台

把「CSM 提需求 → AI 评估 → 产品出 PRD → AI 生成研发提示词 → 研发开发 → AI 生成测试用例 → 测试 → 验收」整条链路做成**可配置的 SOP 流程**，每个节点可绑定 AI 动作。

## 功能
- **角色登录**：CSM / 产品 / 研发 / 测试 / 管理员
- **需求看板（各角色）**：每个角色登录后看到专属看板 —— 统计卡（待处理/流转中/待澄清/已上线）、「待你处理」队列、「进行中」列表，卡片展示当前 SOP 节点、等级、待补充标记
- **需求列表（各角色）**：表格 / 看板双视图，支持搜索、按状态 / 等级 / 紧急度筛选，看板视图按当前 SOP 节点分列
- **需求流转**：状态机由 SOP 模板节点驱动，支持打回（必填原因）、澄清问答、**强制提交**
- **AI 节点**：完整性预检 / 需求评估定级(L1-L4) / PRD 生成 / 研发提示词 / 测试用例；有问题自动向 CSM 提问
- **管理后台**：人员管理、SOP 节点可视化编排（增删改/排序/绑定 AI 动作/命名）、AI Provider 配置（Claude/OpenAI 兼容/Mock）、主题色/深浅色、数据总览
- **产物留痕**：评估报告、PRD（版本）、研发提示词、测试用例、时间线全留痕

## 快速开始
```bash
# 后端（端口 4000，含静态托管前端）
cd server && npm install && npm start

# 前端开发模式（可选，端口 5173 代理到 4000）
cd web && npm install && npm run dev

# 生产构建
cd web && npm run build   # 产物由 server 直接托管
```

打开 http://localhost:4000

## AI 说明
- 默认使用**内置 Mock**（离线可演示，输出结构化示例）。
- 在「管理后台 → AI 配置」添加真实 LLM（Anthropic Claude / OpenAI 兼容协议，如 Kimi、DeepSeek），启用后自动切换真实调用，失败自动降级 Mock。

## 技术栈
Express + better-sqlite3（WAL） · React 18 + TypeScript + Vite · 无 ORM、零外部服务依赖
